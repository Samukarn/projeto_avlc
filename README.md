# projeto_avlc

Torneio de Álgebra Linear (CIN0138): completar matrizes com valores ocultos.

- `solucao.py` — nossa função `principal(observada, mascara)` (é o arquivo que vai no zip de entrega).
- `testar.py` — testa a solução localmente contra o banco público: `python3 testar.py`
- `testar_sintetico.py` — compara versões em matrizes sintéticas, para não decorar o banco público.
- `dados/` — banco público (observada, mascara, gabarito).
- `EVOLUCAO.md` — diário da evolução da equipe, base da apresentação.

Teste oficial: avaliador Docker (`docker compose up` no pacote do Classroom → http://localhost:8501).
